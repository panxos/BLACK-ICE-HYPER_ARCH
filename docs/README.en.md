The complete guide covers customization, displays, workspaces, software, recovery, laboratories, power, diagnostics and updates in English. The gallery preserves theme names and images. Specialist historical notes and some technical references remain in their original language; their filenames do not constitute interface language support.

Application IDs live in `config/apps.json`. Theme generation uses `dotfiles/waybar/`; translation sources use `config/i18n/`. Keep generated files consistent with their source models.

Private plans, credentials and machine evidence are excluded from the distribution. [Credits and provenance](../CREDITS.md).
