# Contribuir

La guía vigente es [Repository Guidelines](../../CONTRIBUTING.md). Describe estructura, comandos de desarrollo, estilo, pruebas y requisitos de revisión.

Ejecuta `bash scripts/check-project.sh` antes de proponer cambios. Adjunta capturas para cambios visuales y distingue pruebas automatizadas de aceptación física pendiente. No publiques configuraciones privadas ni material de sesión.
